# Ahmet Efe Özçelik — Progress, in a Loop

Kurulum gerektirmeyen statik site (HTML + CSS + JavaScript). Build adımı yok.

## GitHub Pages ile yayınlama
1. GitHub'da **New repository** → adı: `KULLANICIADI.github.io` → **Public** → Create.
2. **uploading an existing file** → bu klasördeki TÜM dosyaları sürükleyin
   (`index.html`, `styles.css`, `loop.js`, `.nojekyll`, `assets/` klasörü) → **Commit changes**.
3. **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. 1–2 dakika sonra: `https://KULLANICIADI.github.io`

## Bilgisayarda önizleme
`index.html` dosyasına çift tıklamanız yeterli.

## Düzenleme
- Doldurulması gereken alanlar `index.html` içinde `[Add ...]` / `[Edit ...]` şeklindedir
  (`class="ph"`). Doldurduktan sonra `<span class="ph">` etiketini kaldırın.
- `og:url` satırındaki `USERNAME` kısmını kendi adresinizle değiştirin.
