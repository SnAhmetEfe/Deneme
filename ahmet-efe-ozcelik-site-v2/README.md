# Ahmet Efe Özçelik — kişisel site

Statik site (HTML + CSS + JS). Kurulum/derleme gerekmez.

## GitHub'a yükleme
Deponun ANA dizinine şu dosyaları yükleyin: index.html, styles.css, main.js, .nojekyll, assets/
Adres: https://snahmetefe.github.io/Deneme/

## Fotoğraf
Fotoğrafınızı `assets/photo.jpg` adıyla yükleyin; otomatik görünür (dikey, ~4:5 oranı ideal).

## Doldurulacak alanlar
index.html içinde `class="ph"` ile işaretli `[...]` alanlar. Doldurunca `<span class="ph">` etiketini kaldırın.
